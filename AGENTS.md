# Minecraft Mods & Resource Packs Guide

This repository is a **GitBook-ready documentation source**, not a web application. It is synced to GitBook via GitHub Git Sync.

## Conventions

- All content is Markdown, compatible with GitBook rendering.
- The navigation structure is defined in `SUMMARY.md`. Add new pages there and keep links valid.
- Use the templates in `templates/` when adding new mods, resource packs, shaders, setups, or comparisons.
- Do NOT add real Minecraft mods, resource packs, shaders, modpacks, screenshots, download links, or performance/compatibility claims unless the repository owner has provided them. Use placeholders instead.
- Keep metadata consistent (category, Minecraft version, mod loader, client/server, performance impact, compatibility).
- Do not fabricate specifications, performance numbers, or compatibility information.
- No build step, no package manager, no frontend code. Verify by checking Markdown files and links.
