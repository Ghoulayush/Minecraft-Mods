# Launcher Setup

> Every Minecraft setup starts with a launcher. This page covers the most popular options and walks through setting up Prism Launcher — the launcher used throughout this guide.

## Choosing a launcherQ

There are multiple launchers and clients available for Minecraft. The official Minecraft launcher works but is widely considered unreliable for modded play.

Here are the most popular options.

### Lunar Client

Lunar Client is an all-in-one client with built-in performance mods, a mod downloader, and a resource pack browser supporting both Modrinth and CurseForge. It offers solid out-of-the-box performance and is used by many content creators, including Flowtives, Swight, and ImMixed.

### Dawn Client

Dawn Client (formerly Feather Client) is another all-in-one client with an integrated mod and resource pack downloader for Modrinth and CurseForge. It is used by content creators such as Dolphin (dol9hin) and Tai_.

> **Note:** Some recent reviews suggest that Dawn Client's performance may have declined since the rebrand. The client is still under active development and these issues may improve over time.

### Modrinth Launcher

Modrinth Launcher is a clean, minimal launcher from the Modrinth team. It provides straightforward instance management with tight integration into the Modrinth ecosystem.

### Prism Launcher

Prism Launcher is a free and open-source Minecraft launcher. It makes creating and managing separate Minecraft instances straightforward, with an interface that is easy to learn for beginners. This guide uses Prism Launcher for all setup walkthroughs.

## Prism Launcher setup

### 1. Download Prism Launcher

Download Prism Launcher from the [official website](https://prismlauncher.org/).

Install it according to your operating system.

![Download options](image.png)

> **Tip:** A command-line installer is also available — scroll down the download page to find it.

### 2. Sign in

After installing, launch Prism Launcher and sign in with the Microsoft account that owns your Minecraft purchase.

### 3. Confirm sign-in

You should see the main launcher window. Ignore any modpacks or entries shown — yours will appear empty since no instances have been created yet.

![Launcher window after sign-in](image-1.png)

### 4. Create an instance

Click the **Add Instance** button. A configuration window will appear.

![Add Instance window](image-2.png)

### 5. Select version and mod loader

Select the Minecraft version you want to play. Scroll down to the mod loader options — by default this is set to **None**. Change it to **Fabric** (latest version).

> **Note:** This guide showcases mods using Fabric, but many of the mods covered also support other mod loaders. Check the description of each individual mod page to confirm compatibility with your preferred loader.

### 6. Confirm and install

Click **OK**. Prism Launcher will download the necessary assets and prepare your instance. This usually takes a few minutes.

Once complete, you will see the new instance in your launcher — ready to play.

![Instance ready to launch](image-3.png)
