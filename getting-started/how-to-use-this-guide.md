# How to use this guide

This guide is organized by goal, not by individual project. Start with the area you care about most and work through the pages in order, or dip in wherever you need.

## Browse by goal

Each top-level section represents a player goal:

| Section | Best for |
|---------|----------|
| [Performance](../performance/overview.md) | Higher FPS, smoother gameplay, lower memory usage |
| [Atmosphere](../atmosphere/overview.md) | Ambient sound, weather, particles, immersion |
| [Visuals](../visuals/overview.md) | Graphics, animations, lighting |
| [PvP](../pvp/overview.md) | Combat, HUD, visibility, competitive play |
| [Resource packs](../resource-packs/overview.md) | Texture changes and visual overhauls |
| [Shaders](../shaders/overview.md) | Lighting and rendering overhauls |
| [Setups](../setups/overview.md) | Curated mod combinations for a specific goal |
| [Comparisons](../comparisons/overview.md) | Choosing between similar options |

> TIP
> If you are new to modded Minecraft, begin with [Launcher setup](launcher-setup.md) to get Prism Launcher and Fabric ready, then move to [Performance](../performance/overview.md).

## Category pages

Every section starts with an **overview page** that explains what the category covers and links to the specific topics inside it. Use the overview page as your table of contents for that section.

## Individual entries

Inside each section you will find pages dedicated to specific items — a mod, a resource pack, a shader, or a setup recipe. Each entry typically covers:

- What it does and who it is for
- How to install it
- Compatibility notes (where known)
- Links to related entries

> NOTE
> Individual entry pages use templates found in the [`templates/`](../templates/) folder. If you plan to contribute, read [CONTRIBUTING.md](../CONTRIBUTING.md) first.

## Setups and comparisons

- **Setups** combine multiple mods, packs, and shaders into a curated package for a single goal (for example, a low-end PC setup or a competitive PvP setup).
- **Comparisons** place similar options side by side — for instance, two shader packs or two performance mods — so you can decide which one fits your needs.

## Searching

Search is handled by the publishing platform (GitBook), not by this repository. Use the search bar on the live site to find pages by keyword.
